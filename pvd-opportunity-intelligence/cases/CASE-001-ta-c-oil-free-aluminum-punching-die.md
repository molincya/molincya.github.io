# CASE-001｜ta-C涂层在无油铝板冲孔模具中的应用与工艺迭代

- **案例类型：** PVD/DLC真实打样案例
- **应用对象：** 1 mm铝板无油冲孔模具
- **核心问题：** 铝材粘附与粘着磨损
- **当前进度：** 第三轮七彩ta-C方案累计冲孔20,000件，模具仍在正常使用
- **数据来源：** 刘军·PVD涂层打样归档

> **结论先行：** 针对1 mm铝板无油冲孔工况，三轮涂层打样依次记录了DLC（5,000件）、七彩ta-C薄膜（10,000件）和加厚七彩ta-C（当前累计20,000件）。第三轮尚未达到最终失效寿命，不能把20,000件写成最终寿命，也不能据此宣称已经验证某一确定寿命倍数。

## 1. 工况与原始基准

| 项目 | 记录 |
|---|---|
| 冲压材料 | 铝板，厚度1 mm；具体牌号未记录 |
| 冲压环境 | 无油 |
| 模具材料 | 模具钢 |
| 模具硬度 | 62 HRC |
| 模具抛光粗糙度 | Ra 0.4 |
| 主要问题 | 铝材粘附、粘着磨损 |
| 客户无涂层基准 | 单件模具冲孔约2,000件 |

三轮打样针对同一类应用工况。已确认三轮均在相同无油环境和冲压条件下进行；但未提供证据证明使用的是完全相同的实体模具，也没有完整记录所有过程参数，因此不将其表述为严格控制全部变量的对照寿命试验。

## 2. 三轮涂层方案与打样结果

### 第一轮｜DLC

| 参数 | 记录 |
|---|---|
| 涂层方案 | DLC |
| 打底层 | CrN（氮化铬） |
| 涂层硬度 | 约2,000 HV |
| 膜厚 | 2 μm |
| 冲孔数量 | 5,000件 |

### 第二轮｜七彩ta-C

| 参数 | 记录 |
|---|---|
| 涂层方案 | 七彩ta-C |
| 涂层硬度 | 4,500–6,000 HV |
| 膜厚 | 0.4 μm |
| 冲孔数量 | 10,000件 |

第二轮膜厚较薄，后续打样考虑到薄膜厚度及涂层缺陷风险，决定增加膜厚。这是工艺调整时的风险考虑，不代表已通过检测确认第二轮涂层存在缺陷。

### 第三轮｜加厚七彩ta-C

| 参数 | 记录 |
|---|---|
| 涂层方案 | 七彩ta-C |
| 涂层硬度 | 约3,000 HV |
| 膜厚 | 2.5 μm |
| 当前累计冲孔数量 | 20,000件 |
| 当前状态 | 模具仍在正常使用，最终失效寿命未确认 |

## 3. 实测结果与当前观察

| 轮次 | 涂层方案 | 硬度记录 | 膜厚 | 冲孔数量 |
|---|---|---:|---:|---:|
| 第一轮 | DLC + CrN打底 | 约2,000 HV | 2 μm | 5,000件 |
| 第二轮 | 七彩ta-C | 4,500–6,000 HV | 0.4 μm | 10,000件 |
| 第三轮 | 七彩ta-C | 约3,000 HV | 2.5 μm | 20,000件（当前累计） |

第三轮目前仍在正常使用。现阶段观察到：

- 冲头R角位置出现较明显、较严重的磨损迹象；
- 冲头R角开始出现铝粉粘附；
- 当前累计冲孔数量为20,000件，尚未达到最终失效状态。

因此，20,000件是当前已完成的冲孔数量，不是最终寿命。

## 4. 工程判断与数据边界

1. **三轮打样显示出继续验证价值。** 现有记录分别为5,000、10,000和当前累计20,000件；第三轮仍在使用，结果需要继续跟踪。
2. **不能把结果变化单独归因于膜厚。** 第二轮和第三轮的膜厚、硬度记录均不同，缺少足够证据将冲孔数量变化归因于某一个参数。
3. **当前失效观察集中在冲头R角。** 后续应重点跟踪该处磨损发展、铝粉粘附和最终失效判定。
4. **不能将经验区间写成本案例结论。** 工程经验中，ta-C在此类应用上的寿命提升可作为约2–10倍的探索区间；但本案例尚未完成最终寿命验证，不能据此认定已实现某一确定倍数。

## 5. 后续验证重点

- 持续记录第三轮累计冲孔数量，直至达到明确的失效判定标准；
- 对冲头R角进行阶段性拍照和磨损检查，记录粘铝程度；
- 补齐铝板牌号、冲压速度、冲裁间隙及R角尺寸；
- 明确硬度、膜厚测试方法和重复试验情况；
- 若开展下一轮迭代，应尽量固定其他工况变量，使膜厚、硬度或膜系等单一变量的影响更容易判断。
